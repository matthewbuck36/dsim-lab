# Description

This folder contains files which were created to simulate extremum
seeking control papers with a vehicle in Gazebo. Folders in this
directory contain configuration files which match simulations or examples
presented in these papers.

To add a new folder to this directory, please title it with the following format:
Folder Name: "{primary author last name}_{publication year}"
Please add all config files used to match results from this paper in this new directory.
Please also include a pdf version of the paper in this directory, along with a text file
to provide some description of the work done. The text file should follow the template
provided in the [description template](/paper_recreations/description_template.txt) text file.

Please do not put any simulation results in this directory. Any and all simulation results,
figures, or data should be saved on the user's local machine. This repository is only meant
to hold config files, not simulation results.
