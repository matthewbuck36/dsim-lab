This text file holds configured objects written as dictionaries.
These can be copy pasted into the math simulation script to change out
what objects are used in a simulation.

ANGULAR POSITION SIGNALS:

    {
        "spin_rpm": spin_rpm
    }
)

    {
        "spin_rpm": spin_rpm,

    }
)



ESTIMATION SIGNALS:
