# Description

This folder contains part files used to model the Turtlebot3 with a rotating sensor in Gazebo. The parts organized under the printable parts folder should be printed for implementation on the real Turtlebot3 vehicle. The parts organized under the visual model folder do not need to be printed, rather they are used to create a more detailed visual model of the vehicle.

Note the involute gear file was generated with a [free gear generator](https://evolventdesign.com/pages/spur-gear-generator?srsltid=AfmBOoogTM2k90yvJSJE8AIDg6mVZfYctjgemIo1QBgbrCK9HBEJaVt8). The following parameters were used for the design:

- Gear 1 Tooth Count: 56
- Gear 2 Tooth Count: 56
- Module: 1
- Pressure Angle (degrees): 20
- Clearane (mm): 0.05
- Gear 1 Center Hole Diameter (mm): 0
- Gear 2 Center Hole Diameter (mm): 0

Which results in the following properties:

- Gear Center Distance (mm): 56
- Gear 1 Pitch Circle Diameter (mm): 56
- Gear 1 Outer Circle Diameter (mm): 58
- Gear 2 Pitch Circle Diameter (mm): 56
- Gear 2 Outer Circle Diameter (mm): 58
