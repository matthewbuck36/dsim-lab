# HeavyBall PDE ESC Archive

This folder stores historical HeavyBall baseline/reference material that is no
longer part of the active ROS launch surface.

```text
controller_configs/       # retired baseline speed-regime controller configs
cost_function/            # retired sweep and report cost maps
scenarios/baseline_tests/ # baseline scenarios used by the report
scenarios/reference_runs/ # older reference scenarios
work_logs/                # session summaries and implementation notes
```

Active Gazebo scripts and active cost/controller configs remain under
`ros2_ws/src`.
